# Política de publicação

1. Uma nota nasce como `draft` e recebe uma fonte identificável.
2. Outra pessoa ou o responsável do agente move a nota para `in-review`.
3. Somente conteúdo factual, vigente e testável recebe `approved`.
4. A publicação inclui apenas notas aprovadas já vigentes, ainda não expiradas e com sensibilidade
   autorizada, e gera uma versão imutável do índice.
5. Conteúdo substituído passa para `retired`; não é apagado sem necessidade de auditoria.
6. Toda publicação roda avaliações e permite rollback para a versão anterior.

Conversas e dados operacionais nunca são promovidos automaticamente para conhecimento.
